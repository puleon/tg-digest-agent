Словарь

Абляция
Эксперимент, в котором по одной добавляют или убирают части системы, чтобы измерить вклад каждой (12).
Агент
Программа, в которой модель участвует в принятии решений внутри многошагового процесса с действиями между шагами (1, 9).
Асинхронность
Стиль программы, в котором ожидание (await) отдаёт управление другим задачам (13).
Байесовское сглаживание
Подтягивание оценки по малым данным к общему среднему с весом «воображаемых» наблюдений (11).
Бейзлайн
Простое решение, с которым сравнивают систему; слабый бейзлайн делает победу бессмысленной (11, 17).
Би-энкодер
Модель, превращающая запрос и документ в векторы по отдельности; векторы документов считаются заранее (8).
Вето (cannot-link)
Запрет объединять два поста в один кластер, даже если их связывает цепочка рёбер (7).
Грамматика (GBNF)
Правила, ограничивающие, какие токены модель может выдать; строится из JSON-схемы (3).
Деградация
Продолжение работы с частичным результатом при сбое шага, с пометкой о нём (10).
Дистилляция
Обучение лёгкой модели повторять ответы большой (6).
Идемпотентность
Свойство операции давать тот же результат при повторном выполнении (4, 5).
Инъекция промпта
Текст в данных, пытающийся управлять моделью; косвенная — когда его пишет посторонний (10).
Каппа Коэна (κ)
Согласие двух оценщиков сверх случайного: 1 — полное, 0 — как случайное (12).
Квантование
Хранение весов модели с меньшей точностью (4–5 бит), чтобы она меньше весила и быстрее работала (3).
Контейнер
Процесс с изолированным видом на систему (свои процессы, файлы, сеть) на общем ядре хоста (15).
Контекст
Окно токенов, которое модель видит за один вызов (3).
Кросс-энкодер, реранкер
Модель, читающая запрос и документ вместе и выдающая оценку соответствия (8).
Курсор
Номер последнего собранного сообщения канала, с которого продолжается сбор (4).
Маршрут, таблица маршрутов
Строки ядра «подсеть → интерфейс»; из подходящих побеждает самый длинный префикс (15).
Наблюдение (observation)
Элемент трейса: вызов модели, поиск, инструмент (14).
Промпт
Текст, который подаётся модели: инструкция, данные, история (3).
Пулинг
Разметка только объединения топов всех сравниваемых систем вместо всего корпуса (12).
Раздельное туннелирование (split tunneling)
VPN только для части адресов: у сервера через туннель идут лишь подсети Telegram (4, 15).
Роутер (llama-server)
Режим сервера моделей, обслуживающий несколько моделей на одном адресе с загрузкой по требованию (3).
Слот
Независимое «рабочее место» сервера модели для параллельного запроса (3).
Сэмплинг, temperature
Способ выбора следующего токена из распределения; при 0 — всегда самый вероятный (3).
Токен
Кусок текста — единица, которой модель читает и пишет (3).
Том (volume)
Хранилище данных, живущее отдельно от контейнера (15).
Трейс
Запись одной операции со всеми вложенными шагами, временем и токенами (14).
Эмбеддинг
Вектор, описывающий смысл текста так, что похожие тексты близки (8).
AUC
Вероятность, что случайный положительный пример получит оценку выше случайного отрицательного (11).
BM25
Классическая формула поиска по словам: частота слова, его редкость, длина документа (8).
DNS Docker
Встроенный сервер имён (127.0.0.11), по которому контейнеры одной сети находят друг друга (15).
Few-shot
Показ модели нескольких образцов правильных ответов прямо в промпте (6).
Function calling
Протокол, в котором модель отвечает заявкой на вызов инструмента с аргументами (9).
Healthcheck
Команда, которой Docker проверяет, что сервис в контейнере готов (15).
HNSW
Многослойный граф для быстрого приближённого поиска ближайших векторов (8).
KV-кэш
Сохранённые промежуточные данные модели для каждого токена контекста (3).
LangGraph
Библиотека, описывающая агента графом: состояние, узлы, рёбра (6, 9).
Long polling
Получение обновлений, при котором клиент держит открытый запрос, пока не появятся данные (13).
MoE (смесь экспертов)
Архитектура, где на каждый токен работает лишь несколько «экспертов» из многих (3).
MRR
Среднее 1 / (место первого подходящего результата) (12).
nDCG@k
Качество порядка выдачи с учётом степени релевантности, нормированное на идеальный порядок (12).
OCR
Распознавание текста на изображении (2, 3).
Payload
JSON-паспорт точки в Qdrant, по полям которого фильтруется поиск (8).
pHash
Перцептивный хэш: 64 бита, почти не меняющиеся при пережатии картинки (7).
Prefill / decode
Чтение промпта пачкой и генерация по одному токену; первое упирается в вычисления, второе — в память (3).
recall@k
Доля всех подходящих документов, попавших в первые k результатов (12).
RRF
Слияние нескольких ранжированных списков по сумме 1 / (60 + место) (8).
SSH-туннель
Переброска соединений через SSH: локальная (к сервису на сервере) и обратная (из сервера наружу) (4, 15).
systemd, юнит, таймер
Менеджер служб Linux, файл-описание службы (команда, каталог, перезапуск) и юнит-расписание, который запускает службу в заданное время (13).
TUN-устройство
Виртуальный сетевой интерфейс, пакеты которого читает и пишет программа — например, клиент VPN (15).
Union-find
Структура данных для быстрого объединения элементов в группы (7).
